# Paradise Nursery Shopping Application

Paradise Nursery is a React-based houseplant shopping application created as a final project.

## Project Name
**Paradise Nursery Shopping Application**

## Features
- Landing page with Paradise Nursery branding and Get Started button
- About Us page
- Product listing with 18 unique houseplants across 3 categories
- Add to Cart functionality using Redux Toolkit
- Dynamic cart item count
- Cart quantity increase/decrease controls
- Delete items from cart
- Total cost per item and total cart amount
- Checkout "Coming Soon" message
- Continue Shopping navigation
- Responsive styling and plant-themed UI

## Technologies
- React
- Vite
- Redux Toolkit
- React Redux
- React Router
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

# Paradise Nursery Shopping Application

Paradise Nursery is a React-based shopping application for browsing and purchasing houseplants.

## Project Details

The application allows users to browse different categories of houseplants, view product details, add plants to a shopping cart, manage quantities, and view the total cart amount.

## Features

- Browse houseplants
- Multiple plant categories
- Add plants to cart
- Increase and decrease product quantity
- Remove products from cart
- View shopping cart total
- Checkout functionality
- Continue shopping option
